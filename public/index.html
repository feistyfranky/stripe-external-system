Stripe CLI Integration & Webhook Forwarding

To connect your local external system to real Stripe test events dispatched from your Stripe dashboard:

1. Install & Login with Stripe CLI

# Install via Scoop (Windows) or download stripe.exe
scoop bucket add stripe https://github.com/stripe/stripe-cli.git
scoop install stripe

# Log into your Stripe account
stripe login

2. Forward Events to This External System

Run the forwarder in a terminal window. It will capture events from Stripe and forward them directly to your raw webhook receiver:

stripe listen --forward-to localhost:3000/api/webhooks

3. Configure Webhook Secret in .env

The CLI will output: Your webhook signing secret is whsec_...

Copy that secret into your .env file:

STRIPE_SECRET_KEY=sk_test_51...
STRIPE_WEBHOOK_SECRET=whsec_...

4. Trigger Test Events via CLI

# Trigger checkout session
stripe trigger checkout.session.completed

# Trigger subscription created
stripe trigger customer.subscription.created

# Trigger invoice payment
stripe trigger invoice.paid
